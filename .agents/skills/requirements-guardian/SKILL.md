# Requirements Guardian

## Goal

Prevent missing mandatory functionality and prevent bonus work from displacing core scoring areas.

## Procedure

1. Read `docs/01_PROJECT_BRIEF.md` and `docs/02_REQUIREMENTS_TRACEABILITY.md`.
2. Map the requested task to requirement IDs and evaluation areas.
3. Identify dependencies and acceptance evidence.
4. Reject or defer tasks that are unrelated to a core requirement unless the core is complete and the task is an approved bonus.
5. After implementation, verify code, tests, and browser artifact rather than relying on a claim.
6. Update traceability status and list remaining blockers.

## Output

- Requirement IDs addressed.
- Acceptance criteria.
- Evidence found.
- Missing or partially satisfied behavior.
- Scope recommendation: proceed, revise, defer, or reject.
