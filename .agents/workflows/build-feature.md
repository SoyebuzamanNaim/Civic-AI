# Build Feature

1. State the feature, requirement IDs, owner, reviewer, and forbidden scope.
2. Read the relevant architecture, API, data, security, and skill files.
3. Inspect existing code and reuse established contracts.
4. Write a brief plan listing files, schema/API changes, tests, and rollback risks.
5. Implement the smallest complete vertical slice.
6. Run formatting, typecheck, lint, focused tests, and production-relevant checks.
7. Start the app and verify the acceptance path in the browser at phone and desktop widths.
8. Check public/private data boundaries and error states.
9. Update traceability and any affected ADR/API/schema docs.
10. Produce an artifact with changed files, test results, screenshots, known limitations, and next task.
