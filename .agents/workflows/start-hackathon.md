# Start Hackathon

1. Verify the repository was created after the official event start and is public as required.
2. Read `README.md`, all `docs/`, `.agents/agents.md`, and workspace rules.
3. Inspect installed skills and flag any untrusted or unnecessary package before use.
4. Check the local prerequisites and environment-variable names without printing secret values.
5. Produce:
   - `artifacts/IMPLEMENTATION_PLAN.md`;
   - `artifacts/ROUTE_MAP.md`;
   - `artifacts/DATA_PERMISSION_MATRIX.md`;
   - `artifacts/ADR_INDEX.md`;
   - `artifacts/TASK_BOARD.md` for four people.
6. Map each planned task to a requirement ID.
7. Identify decisions needing human approval.
8. Stop and request plan approval before feature implementation.
